# 🛒 Next Cart – 360° Business Intelligence Dashboard

## 📌 Project Overview

This **Excel Dashboard** provides a **comprehensive business intelligence solution** for **Next Cart**, a fictional e-commerce company operating across Bangladesh. It consolidates **Sales, HR, and Inventory** analytics into a single, professionally designed Excel workbook — enabling data-driven decision-making across all three core business domains.

The dashboard is built using **advanced Excel functionalities**, including:

- 📊 Pivot Tables & Pivot Charts
- 🔘 Slicers & Interactive Filters
- 🧮 Advanced Formulas & Nested IFs
- 🗺️ Geographic Map Visual
- 🎨 Custom Dashboard Design (Dark Theme)
- 📐 KPI Cards, Gauge Charts & Donut Charts

---

## 📊 Key Insights

### 1️⃣ Sales Performance
- **Total Revenue:** 182,205K BDT with a **49% Profit Margin**
- **Quantity Sold:** 125,113 units across 12,000 transactions
- **Top Location:** Dhaka (29.69% revenue share)
- **Most Profitable Product:** Smartphone – Budget
- **Top Payment Method:** bKash (24.93M BDT)
- **Most Profitable Age Group:** 25–34

### 2️⃣ HR Insights
- **Total Employees:** 500 across 8 departments and 5 regions
- **Gender Split:** 54% Male, 46% Female
- **Average Performance Rating:** 3.378 / 5
- **Highest Headcount Region:** Dhaka (228 employees)
- **Top Salary Role:** Process Improvement Specialist (765,964 BDT)
- **Employment Breakdown:** Full-Time 342 | Contract 106 | Part-Time 52

### 3️⃣ Inventory Status
- **Total Inventory Value:** 73.77M BDT across 4 categories
- **Total Stock Quantity:** 310K units
- **Product Expired Ratio:** Only **3% expired** — 97% stock is active
- **Best Inventory Grade:** GRADE-2 (28.71M BDT value)
- **Average Product Rating:** 3.21 / 5
- **Coverage:** 63 districts across all 8 divisions of Bangladesh

## 🔧 Excel Features Used

| Feature | Application |
|---|---|
| ✅ Pivot Tables | Driving all dashboard charts dynamically |
| ✅ Slicers | Department, Pay Grade, Category, Region, Location filters |
| ✅ Nested IF Formulas | Expiry classification (< 1M, 1M+, 2M+, 3M+, Expired) |
| ✅ KPI Cards | Revenue, COGS, Profit, Margin, Employee Count, etc. |
| ✅ Donut & Gauge Charts | Gender split, performance rating, price category |
| ✅ Bar & Horizontal Charts | Revenue by location, age group, payment method |
| ✅ Map Visual | Division-wise stock status across Bangladesh |
| ✅ Conditional Formatting | Color-coded product ratings and grade highlights |
| ✅ Data Engineering | Calculated columns: Age Group, Price Type, Week Type, Exp_Months |

## 📋 Workbook Structure

| Sheet | Type | Description |
|---|---|---|
| Sales Dashboard | 📊 Dashboard | Interactive sales KPIs and charts |
| HR Dashboard | 📊 Dashboard | Employee metrics and HR analytics |
| Inventory Dashboard | 📊 Dashboard | Stock status and inventory insights |
| Sales Data | 📄 Raw Data | 12,000 transaction records |
| Employee Data | 📄 Raw Data | 500 employee records |
| Inventory Data | 📄 Raw Data | 2,000 inventory records |
| Sales Resources | ⚙️ Pivot Sheet | Aggregated pivot data for Sales Dashboard |
| Employee Resources | ⚙️ Pivot Sheet | Aggregated pivot data for HR Dashboard |
| Inventory Resource | ⚙️ Pivot Sheet | Aggregated pivot data for Inventory Dashboard |

## 💡 Recommendations

- 📦 **Inventory:** Investigate the 3% expired stock — focus on GRADE-1 products in the Southern region which show higher expiry counts
- 💰 **Sales:** Expand marketing efforts in Chittagong (18.39%) and Sylhet (9.72%) to close the gap with Dhaka
- 👥 **HR:** The 19% remote workforce indicates flexibility — consider structured remote performance KPIs
- 📱 **Products:** Smartphone – Budget is both the top seller and most profitable; consider upselling premium variants to the 25–34 age group
